# Rak Baca (PWA)

Aplikasi pencatat bacaan. React + Vite + Tailwind + vite-plugin-pwa + axios (Disclamer aplikasi ini tidak diperlukan database dan dijalankan secara lokal).

**Halaman:** Rak (CRUD buku) · Statistik · Profil (nama, NIM, kelompok)

## Menjalankan
```bash
npm install
npm run dev        # pengembangan
npm run build && npm run preview   # uji PWA (service worker aktif di mode ini)
```

## Isi data profil
Edit `src/config/profile.js` (nilai default), atau ubah dari halaman **Profil** di aplikasi.

## Penyimpanan data
- **Default:** localStorage. Tidak butuh server, CRUD jalan penuh saat offline.
- **Opsional Supabase:** salin `.env.example` menjadi `.env`, isi URL dan key. Jalankan SQL di bawah pada SQL Editor Supabase.
  Di Vercel, tambahkan dua variabel yang sama di Settings → Environment Variables.

```sql
create table if not exists public.books (
  id bigint generated by default as identity primary key,
  title text not null,
  author text,
  status text not null default 'want' check (status in ('want','doing','done')),
  rating integer not null default 0 check (rating between 0 and 5),
  notes text,
  created_at timestamptz not null default now()
);
alter table public.books enable row level security;
grant select, insert, update, delete on public.books to anon, authenticated;
grant usage, select on sequence public.books_id_seq to anon, authenticated;
-- Akses publik penuh: hanya untuk demo/tugas.
create policy "public all books" on public.books for all to anon, authenticated using (true) with check (true);
```

## Deploy ke Vercel
```bash
git init && git add . && git commit -m "Rak Baca PWA"
git branch -M main
git remote add origin <link-repo-github>
git push -u origin main
```
Lalu di Vercel: Add New → Project → pilih repo → Deploy (preset Vite terdeteksi otomatis).
Routing memakai hash (`#/rak`), jadi tidak perlu konfigurasi rewrite.

## Cek PWA
1. Buka link Vercel di Chrome → ikon *Install* muncul di address bar (atau banner "Pasang Rak Baca").
2. DevTools → Application → Service Workers: status *activated*.
3. Centang *Offline* di tab Network lalu reload: aplikasi tetap terbuka dan CRUD tetap jalan.
